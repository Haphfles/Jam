A band with an open door.

Open the stage on a computer, invite up to five phones, and start the clock. Each phone controls one instrument. Sound comes only from the computer.

Record loop arms a four-bar recording at the next bar. Your notes are snapped to sixteenths, then repeat. Stop loop keeps your recording; Clear loop erases it. Live notes always remain available while the host clock runs.

The host sets tempo while stopped. Stopping the clock silences the stage; starting again restarts saved loops together. Backgrounding the host stops playback to prevent delayed audio.

GitHub Pages serves the app; Supabase Realtime carries small control messages. No Node server or phone app. This version plays audio locally at the host, not through remote listeners’ browsers. Phone latency varies; late notes are dropped rather than replayed.
